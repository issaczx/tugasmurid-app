RPD Bagian 7 • Arsitektur Tanpa Server Bulanan

Tri-Faktor Infrastruktur Hemat & Andal

Bagaimana TugasMurid dapat melayani ratusan murid dengan biaya server Rp 0 melalui kombinasi GitHub Pages, Cloudflare Edge, dan Git-Ops Database.

devices
Komponen 1

Frontend Statis (GitHub Pages)

Aplikasi berbasis HTML/Tailwind/Vanilla JS statis murni yang dimuat dalam <1 detik dari cache CDN global. Sangat ramah kuota bahkan di koneksi EDGE/3G ponsel murid.

speed Kecepatan Muat: ~200ms
bolt
Komponen 2

Perantara Cerdas (Cloudflare Workers)

Worker micro-API tanpa server (Serverless) yang bertugas memvalidasi password guru/admin, memfilter izin unggah, dan mengamankan GitHub Personal Access Token agar tidak bocor ke klien.

security Enkripsi Token & Rate-Limiting
folder_special
Komponen 3

Database Git Privat (GitHub Repo)

Setiap tugas tersimpan sebagai commit JSON terstruktur dan lampiran WebP di repositori privat sekolah. Lengkap dengan riwayat log audit (versi), rollback instan, dan bebas biaya basis data bulanan.

Tanya Jawab Seputar TugasMurid

Informasi praktis seputar kuota, data privasi, dan kelancaran belajar mengajar.

Apakah siswa membutuhkan kuota besar untuk mengirim foto tugas? expand_more
Sama sekali tidak. Sesuai spesifikasi RPD 7.4, mesin browser siswa secara otomatis mengonversi dan mengompresi foto beresolusi tinggi ke format WebP ringan (~300–500 KB per lembar) sebelum paket data dikirim ke server. Satu foto tugas hanya memakan kuota setara satu pesan stiker aplikasi chat.
Bagaimana jika murid lupa kata sandi atau salah memasukkan NIS? expand_more
Platform tidak membebani siswa dengan prosedur pemulihan email yang rumit. Jika ada murid yang mengalami kendala login, wali kelas dapat mereset PIN atau memeriksa validitas NIS dalam 5 detik langsung dari Konsol Manajemen Kelas.
Apakah data foto tugas dan nilai siswa aman dari publik? expand_more
Sangat aman. Seluruh data nilai dan foto tugas tersimpan dalam repositori privat yang terenkripsi dan terisolasi. Jalur pengiriman diverifikasi melalui Cloudflare Workers Edge Gateway yang mengamankan kredensial serverless sekolah, sehingga orang asing tidak dapat mengakses arsip kelas.
Bisakah sekolah saya mengadopsi TugasMurid secara gratis? expand_more
Ya, arsitektur RPD v1.4 dirancang khusus untuk memanfaatkan kuota gratis infrastruktur GitHub Pages dan Cloudflare Workers Free Tier. Sekolah dapat melayani kebutuhan belajar mandiri hingga ±500 siswa aktif tanpa tagihan VPS bulanan.
